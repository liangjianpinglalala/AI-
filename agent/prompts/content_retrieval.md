# 内容检索 Prompt（草稿）

## 目标

给定用户输入的古诗名或成语，输出结构化的知识 JSON，供后续脚本生成步骤使用。禁止编造不确定的史实/出处；不确定时明确标注。

## 输入

- `query`: 用户输入的原始字符串（如“静夜思”或“画蛇添足”）

## 输出 JSON Schema（草稿）

```json
{
  "query_type": "poem | idiom",
  "title": "标题",
  "author": "作者（成语可为 null）",
  "dynasty": "朝代（成语可为 null）",
  "original_text": "原文",
  "translation": "逐句/整体译文",
  "background": "创作背景或典故出处",
  "meaning": "含义/寓意/情感解读",
  "example_usage": "用法示例（主要用于成语）"
}
```

## 注意事项

- 优先结合本地可信数据源（古诗文数据集/成语词典）做检索比对，模型只负责组织语言，而不是凭记忆生造内容。
- 找不到对应词条时，返回明确的“未找到”状态，交由上层决定如何提示用户，而不是臆造一个近似结果。
